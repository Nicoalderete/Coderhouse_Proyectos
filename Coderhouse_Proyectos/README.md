# Coderhouse_Proyectos
Proyectos realizados en la plataforma de aprendizaje Coderhouse


### Descripción General

En este repositorio se encuentran proyectos desarrollados durante diferentes cursos en la plataforma de aprendizaje Coderhouse, enfocados en construir una base sólida de conocimiento práctico y demostrable en Analítica de Datos. 

Los primeros tres proyectos comparten un conjunto de datos de ventas obtenido del sitio Kaggle.com, que puedes encontrar [aquí](https://www.kaggle.com/datasets/vincentcornlius/sales-orders). Cada uno de estos proyectos representa el análisis del mismo conjunto de datos desde un enfoque analítico diferente utilizando herramientas como Excel, Tableau y Power BI.

El cuarto proyecto, por otro lado, consiste en una base de datos creada con MySQL específicamente para que los usuarios puedan gestionar y analizar sus finanzas personales. Este incluye funcionalidades como el registro y análisis de ingresos, gastos, inversiones y presupuestos, facilitando así la toma de decisiones financieras informadas.

Cada proyecto fue elaborado durante semanas o meses, constituyendo la entrega final necesaria para aprobar los cursos y obtener las certificaciones correspondientes.



### Dataset Utilizado
Fuente: [Sales Orders Dataset](https://www.kaggle.com/datasets/vincentcornlius/sales-orders)

Descripción: El dataset incluye un conjunto de órdenes de ventas, proporcionando información detallada sobre las ventas realizadas durante un periodo específico.

### Proyectos Incluidos
1.Procesamiento de Datos en Excel:  
  Análisis exhaustivo de las ventas utilizando herramientas avanzadas de Excel, como tablas dinámicas y gráficos.


2.Análisis del Dataset en Tableau:  
  Visualizaciones y análisis interactivo de las ventas utilizando Tableau.


3.Análisis de Ventas con Power BI:  
  Analisis y reporte avanzado de las ventas utilizando Power BI.


4.Proyecto SQL:  
  Gestión y análisis de la base de datos de ventas utilizando SQL.
